Ransom, a chess engine

Finalist

My Optiver AI Chessathon engine: pure Python source, no compiled files submitted.

  • 450–500 teams, UK and global
  • 30th rank going into the finals
  • 7 · 4 · 2 wins, draws, losses
  • Last 32 where it went out
  • Python
  • numba
  • PyTorch for training

AI use

  1. none
  2. assisted
  3. vibecoded

Assisted. Built during the competition with Claude Code, as its own write-up says.

Play it in your browser→Code and write-up→

More

The rules banned existing engines and models, and would not accept compiled programs. So the whole engine is Python. It looks ahead through the possible moves, using SEE pruning to skip moves that clearly lose material. A small neural network, trained during the event, judges each position.

My part
All of it. I worked on it alone.
  • The network was trained on 106,814,205 positions.
  • The version on the Play page is the same engine rewritten in C so a browser can run it. On 104 test positions it chooses the same move, with the same score, as the original.

    Machine learning, by hand

    Complete

    Linear and logistic regression written by hand, to see how they work inside.

    • 2 algorithms, written by hand
    • 2.000, 1.000 what it finds for the line y = 2x + 1
    • Python
    • numpy

    AI use

    1. none
    2. assisted
    3. vibecoded

    None. I coded these myself.

    Code→

    More

    Each one learns by gradient descent: make a guess, measure the error, nudge the numbers a little, and repeat. Given points on the line y = 2x + 1, the linear one finds 2.000 and 1.000. The logistic one uses the sigmoid function to sort numbers into two groups.

    They are small. Each one handles a single input number, and there are no plots yet.

    My part
    All of it.

    A web server

    Complete

    A small web server in Python that reads requests straight off the connection.

    • 0 web libraries
    • 1 thread per connection
    • All tests passed
    • Python
    • socket
    • threading
    • gzip

    AI use

    1. none
    2. assisted
    3. vibecoded

    None. No AI.

    Code→

    More

    It uses only what comes with Python, no web library, and writes the replies itself. It can echo text back, compressed with gzip when the caller asks for that, and report which program is calling. It can serve and save files in a folder, keep a connection open for several requests, and give each connection its own thread.

    Built on the CodeCrafters “Build your own HTTP server” challenge. All tests passed.

    My part
    All of it.

    What it does not do

    • It only answers on the machine it runs on.
    • A badly formed request gets no reply. The connection just closes.

    More

    Git is the tool programmers use to keep the history of their code. Starting from the CodeCrafters starter, this can store a file the way git stores it (SHA-1 hash, zlib compression) and read stored files back. It can list what is in a stored folder, record a folder as a tree, and write a commit.

    Its clone command asks a server for its branches and downloads the packed data, but does not unpack it yet. Built on the CodeCrafters “Build your own Git” challenge.

    More
