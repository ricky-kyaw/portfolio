Ransom, a chess engine

My entry in the Optiver AI Chessathon. Finalist out of 450–500 teams (UK and global).

The rules banned existing engines and models, and would not accept compiled programs. So the whole engine is Python. It looks ahead through the possible moves, using SEE pruning to skip moves that clearly lose material. A small neural network, trained during the event, judges each position.

It qualified for the finals ranked 30th, with 7 wins, 4 draws and 2 losses, and went out in the last 32.

My part
All of it. I worked on it alone.
AI use
Built during the competition with Claude Code, as its own write-up says.
Tools
Python, numba, PyTorch for training
More about it
  • The network was trained on 106,814,205 positions.
  • The version on the Play page is the same engine rewritten in C so a browser can run it. On 104 test positions it chooses the same move, with the same score, as the original.

  • May 2026

    Machine learning, by hand

    Two small learning algorithms written out by hand, to see how they work inside: linear regression and logistic regression.

    Each one learns by gradient descent: make a guess, measure the error, nudge the numbers a little, and repeat. Given points on the line y = 2x + 1, the linear one finds 2.000 and 1.000. The logistic one uses the sigmoid function to sort numbers into two groups.

    They are small. Each one handles a single input number, and there are no plots yet.

    My part
    All of it.
    AI use
    None. I coded these myself.
    Tools
    Python, numpy

  • Jul–Aug 2025

    A web server

    A small web server in Python that reads requests straight off the network connection and writes the replies itself.

    It uses only what comes with Python, no web library. It can echo text back, compressed with gzip when the caller asks for that, and report which program is calling. It can serve and save files in a folder, keep a connection open for several requests, and give each connection its own thread.

    Built on the CodeCrafters “Build your own HTTP server” challenge. All tests passed.

    My part
    All of it.
    AI use
    None.
    Tools
    Python: socket, threading, gzip
    What it does not do
    • It only answers on the machine it runs on.
    • A badly formed request gets no reply. The connection just closes.

  • Aug 2025

    A piece of git

    Some of the inner commands of git, the tool programmers use to keep the history of their code, written again in Python.

    Starting from the CodeCrafters starter, it can store a file the way git stores it (SHA-1 hash, zlib compression) and read stored files back. It can list what is in a stored folder, record a folder as a tree, and write a commit.

    Its clone command asks a server for its branches and downloads the packed data, but does not unpack it yet. In progress. Built on the CodeCrafters “Build your own Git” challenge.

    My part
    All of it.
    AI use
    None.
    Tools
    Python: zlib, hashlib, requests

  • 2026

    Nemo, a money tracker

    A personal money tracker. You sign in, set up accounts in different currencies, and record income, spending and transfers. Accounts can sit inside other accounts, and receipts can be attached.

    A small server of our own sits between the browser and the main server, so the browser never holds the sign-in tokens. It is live and still being worked on. Three people have written code for it.

    My part
    The first version of accounts, transactions, categories and transfers on the main server. Much of the sign-in work: the PIN screen, Google sign-in, email verification, lock-out after failed sign-ins and a two-device limit. Moving the whole interface to MudBlazor. Teammates started the in-between server; I extended and repaired it.
    AI use
    We did the backbone and the data model without AI. Now it is all AI-assisted.
    Tools
    C#, .NET, ASP.NET Core, Blazor WebAssembly, MudBlazor, Entity Framework Core, PostgreSQL
    What is not built yet
    • Budgets and reports. Those two pages are empty for now.

    The code is private.

    Explain It!

    Type a topic you find hard and get back a short explanation, written as if for a five-year-old.

    You sign in with your email. The page sends your topic to a small function on AWS, which asks an AI model (Claude 3 Haiku, through Amazon Bedrock) for the answer. It keeps no history: earlier answers are gone when you refresh the page.

    All of it.
    AI use
